# 🏏 IPL Analytics Dashboard

## 📌 Project Overview

This project presents an interactive IPL Analytics Dashboard built using Streamlit, Pandas, and Plotly. The dashboard enables users to explore IPL match data through dynamic visualizations, performance metrics, and interactive filters. It provides insights into team performance, player statistics, venue analysis, and overall match trends.

## 📂 Dataset

- matches.csv
- deliveries.csv

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly Express
- Streamlit

## 📊 Dashboard Features

- Interactive Dashboard
- KPI Cards
- Season Filter
- Team Filter
- Venue Filter
- Player Filter
- Download Filtered Data
- Responsive Dashboard Layout
- Dark Theme Interface

## 📈 Visualizations

- Matches Per Season
- Top Winning Teams
- Toss Decision Analysis
- Top Venues
- Top Run Scorers
- Top Wicket Takers
- Top Six Hitters
- Top Four Hitters

## 🔍 Key Insights

- Analyze IPL performance across different seasons.
- Compare the success of IPL teams based on match wins.
- Identify the highest run scorers and wicket takers.
- Understand toss decision trends and their distribution.
- Explore venue-wise match statistics.
- Interactively filter data by season, team, venue, and player.
- Export filtered match data for further analysis.
